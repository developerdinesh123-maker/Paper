# Invoice Intelligence Agent Team

Document Analyst: classify invoice, packing list, delivery challan, PO and other files.

Extraction Agent: extract only source-supported values; never guess.

Reconciliation Agent: match invoices and packing lists using invoice/PO/shipment/reference number, supplier and dates.

Validation Agent: check totals, units, duplicates, missing fields and confidence.

The user's natural-language request is the source of truth for the output fields.
